# Ybex docs — kya kahan hai

## setup/ — deploy, keys, stores, domain
- `ENV_KEYS.md` — har key kya hai aur kahan se milegi (`.env.example` ke saath)
- `DOMAIN_CLOUDFLARE.md` — ybexmedia.in jodna (Cloudflare free, step-by-step)
- `APP_STORE_CHECKLIST.md` — App Store + Play Store form ke jawab aur links
- `OFFLINE_AND_APP_STORE.md` — offline app kaise kaam karta hai

## code/ — code ke rules aur map
- `CODE_MAP.md` — kaunsa feature kis file mein (shuru yahin se)
- `ARCHITECTURE.md` — saare rules (locked files, loading states, money rules…)
- `PROTECTED_CHANGES.md` — locked files kab aur kyun khule (script khud likhta hai)
- `CONTRIBUTING.md`, `UNIQUE_FEATURES.md`

## database/ — Supabase
- `PENDING_DB_CHANGES.md` — DB changes: kya ho gaya, kya baaki hai
- `SUPABASE_PROMPT*.md`, `SESSION_31/35_SUPABASE_PROMPTS.md`, `UGC_DEADLINE_RELIST_REFUND_SYSTEM.md` — purane Supabase prompts
- SQL files: `scripts/sql/`

## sessions/ — har session ka summary
- Naya summary sabse upar wala number (`SESSION_59_SUMMARY.md` = v337 se).
- `SESSIONS_21_to_57.md` — Session 21–57 ek hi file mein (purana record, kaam ka nahi to kholne ki zaroorat nahi).
